# Salias Phase 1 - A.1 192 B 高吞吐复现报告

**执行日期**：2026-10-19  
**执行人**：Codex

## 一、结论

192 B 高吞吐区**可重复出现，但不是稳定单峰**：20 个正式轮次中位数为
**16.449 Mmsg/s**，较 P1.2 的 17.064 Mmsg/s 仅低 **3.60%**；但 CV=**19.26%**，
范围 8.029–17.381 Mmsg/s。按“中位数 16–18 Mmsg/s 且 CV<5%”的验收门槛，
A.1 **未通过稳定复现判定**。A.2 的前置条件因此未满足。

## 三、判定与限制

- **192 B 高吞吐不是偶然单轮**：多数轮次稳定在约 16–17 Mmsg/s，P1.2 的主结论可重复。
- **仍存在运行时状态切换**：两个约 8 Mmsg/s 的低模式轮，以及 10–13 Mmsg/s 的中间轮，
  说明 192 B 也不是永久锁定在高效路径。
- 20 轮数据不足以把离群归因于 CPU 频率、页表/缓存预热、调度或 ring 状态；A.2 若继续，
  应作为探索性实验而非“已确认预热效应”的验证。
- 本轮只改变轮次数量，未改变 1P2S、50M、CPU0–3、1 MiB ring、batch1、poll-limit64 等配置。

## 四、下一步

不直接进入产品优化。建议先把 A.2 改写为“状态切换定位实验”：固定 192 B 与 64 B 的
交替顺序、记录每组开始前的系统状态，并检查低模式是否可由前一组负载或空闲时长预测。
若 A.2 仍无法稳定控制高/低模式，再转向 CPU 频率、后台服务与隔离等系统级诊断。
