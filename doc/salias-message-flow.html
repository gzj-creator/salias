公共 API 接收消息

Publisher 是用户可见对象，内部持有绑定 Channel 的 Producer/Tx endpoint。

FifoMpsc 语义

每个 Producer 在自己的 MagicRing 内维持 FIFO；单个 Consumer 轮询所有 ring，跨 Producer 的交付次序取决于轮询时机。

分层关系

  • Publisher / Subscriber：L7 公共 API
  • Producer / Consumer：底层 Tx/Rx endpoint
  • Channel：共享状态与端点组织者
  • MagicRing：每个 Producer 独占的数据平面
